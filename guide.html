📋 CV Builder

Buat CV profesional Anda dengan mudah dan ekspor ke PDF

👉 Buka Aplikasi

🚀 Mulai Cepat

Langkah 1: Buka Aplikasi Klik tombol "Buka Aplikasi" di atas untuk memulai membuat CV Anda
Langkah 2: Isi Data Pribadi Mulai dari tab "Data Pribadi" di sisi kiri. Isi nama, email, dan informasi kontak Anda
Langkah 3: Tambahkan Pengalaman Navigasi ke setiap tab (Pendidikan, Pengalaman Kerja, dll) dan tambahkan informasi Anda
Langkah 4: Ekspor PDF Klik tombol "Export PDF" untuk mengunduh CV Anda dalam format PDF profesional

✨ Fitur Utama

  • Form interaktif dengan validasi otomatis
  • Preview CV real-time saat mengisi data
  • Penyimpanan data otomatis di browser Anda
  • Export ke PDF dengan layout profesional
  • Import/Export data dalam format JSON untuk backup
  • Responsif untuk berbagai ukuran layar
  • Tidak memerlukan koneksi internet setelah dimuat

📊 Struktur Bagian CV

Data Pribadi Nama, lokasi, telepon, email, LinkedIn, dan ringkasan profesional
Pendidikan Universitas, gelar, program studi, tanggal, dan IPK
Pengalaman Kerja Perusahaan, posisi, tanggal, dan deskripsi tugas
Pelatihan Judul, institusi, tanggal, dan deskripsi pelatihan
Sertifikat Judul, penerbit, tanggal, dan kredensial
Proyek Teknis Judul, teknologi, dan deskripsi proyek
Volunteer Organisasi, posisi, tanggal, dan deskripsi
Bahasa Bahasa dan tingkat kemampuan

💡 Tips Penggunaan

💾 Penyimpanan Data Data Anda disimpan secara otomatis di browser. Gunakan fitur "Export Data" untuk backup file JSON yang aman.
✏️ Format Deskripsi Untuk pengalaman, pelatihan, proyek, dan volunteer, gunakan format dengan bullet point: • Tugas pertama
• Tugas kedua
Gunakan tombol Enter untuk membuat baris baru
⚠️ Penting! Jika Anda menghapus cache/data browser, data CV Anda akan hilang. Selalu lakukan export data secara berkala untuk backup.
🔄 Import Data Sample Sudah ada file sample-data.json dengan contoh data. Anda bisa mengimpor file ini untuk melihat bagaimana aplikasi bekerja.

📁 Menggunakan Data Sample

Cara Import Data Sample:
  1. Buka aplikasi CV Builder
  2. Klik tombol "Import Data" di sidebar kiri
  3. Pilih file sample-data.json dari folder aplikasi
  4. Data akan otomatis terisi dengan contoh CV

🐛 Troubleshooting

Data hilang setelah refresh? Pastikan browser tidak dalam mode Private/Incognito. Gunakan mode normal untuk penyimpanan data.
PDF tidak tereksport? Pastikan koneksi internet stabil. Library PDF perlu diunduh dari CDN. Nonaktifkan popup blocker jika ada.
Tidak bisa import data? Pastikan file JSON valid. Gunakan data dari "Export Data" atau file sample-data.json.

📞 Dukungan

Aplikasi ini adalah web-based tool yang bekerja sepenuhnya di browser Anda. Tidak ada server atau cloud storage yang terlibat. Data Anda tetap aman di perangkat Anda sendiri.
